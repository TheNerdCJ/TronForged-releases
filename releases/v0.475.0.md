# v0.475.0 - TronForged 0.475.0 - Safer sign-in, clearer accounts

## TronForged 0.475.0 - Safer sign-in, clearer accounts

### Sign-in
- Too many wrong passwords from one PC now lock that name on that PC only. Someone guessing at a staff name or a customer's email from one machine can no longer lock that person out everywhere.
- The limit on reusing an old password now survives a server restart.
- Changing your own password in the Server Console now asks for your current password first.
- A customer login without repair tools is turned away on a customer's PC before it is asked to set a new password.

### Accounts
- Users & groups now lists staff logins and customer logins separately. Each customer login shows the person and the customer it belongs to, and whether its backups are on hold, with an "Allow backups" button.
- Imported users must meet the password rules, and adding or importing users is recorded in the audit log.
- A billing email must be a single address.

### Email
- The "From name" you set in the Server Console is now the sender name on every email the shop sends. If it is blank, the shop name is used.
- The gap between emails can be set from 0 to 60 seconds.
- The ticket-update limit per recipient now counts per customer account, so a shared inbox no longer holds back other accounts.
- Records of finished email sends are deleted after two years.

### Server
- Before any database upgrade, the server now copies the database to backups\db. If the copy fails, the upgrade does not run and the server does not start.

### Messages
- In a ticket's messages, "You" now means this PC. Replies from other people on the customer's side show their name.
- Sending a portal reply again after a failure no longer creates a duplicate.

### What to do
- Update the shop server and consoles as usual.
- Make sure the server's disk has room for one extra copy of the database before upgrading.
- Check the From name in the Server Console email settings.
