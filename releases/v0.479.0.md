# v0.479.0 - TronForged 0.479.0 - Connect with Square, one support download, a tray for every user

## TronForged 0.479.0 - Connect with Square, one support download, a tray for every user

### Connect with Square
Each shop can now link its own Square account from the Server Console's Square page with
**Connect with Square**. Square shows its own sign-in page; when you approve, Square shows a
code on a TronForged return page. Paste that code back into the Server Console and press
**Finish connecting**. The server keeps the access approval sealed, renews it before it
expires, and **Disconnect** removes it. Pasting a Square token by hand still works.

When a Shop connects its own Square account, Square sends the Shop's server an access approval,
which the server keeps sealed and uses only to reach that Shop's Square account. The Shop can
disconnect at any time, from the Server Console or from Square.

### Temporary Fleet: the support download is the full console
The one-time support download is the full TronForged console, started in support mode. It runs
one attended session and installs nothing unless you allow the technician to install
TronForged. The server hands out the newest console release in its release store, so a shop
needs a published console release on its server for the PIN page to offer the download.

### A tray icon for every Windows user
A per-user tray program may run in your Windows session without administrator rights. It talks
only to the TronForged service on this PC. From it a standard user can see the PC's status,
ask the shop for support, or open TronForged. A short console window may flash at sign-in.

### Safer downloads and modules
- A Windows ISO the console downloads is checked against Microsoft's published SHA-256 values
  where the console knows them, and is shown as UNKNOWN where it does not.
- PowerShell Gallery modules are loaded only when every file is signed by that module's known
  publisher.

### Fixes
- Reconnecting to the same saved PC within 10 minutes keeps the ticket and intake you had.
- Removing card numbers from records now checks each change before it is saved, so a removal
  can never leave a new card number behind.

### What to do
- Update the shop server and the consoles as usual.
- To use Connect with Square, open Server Console -> Square and press Connect with Square.
  If Disconnect cannot confirm the removal with Square, also remove the app in your Square
  Dashboard.
- Temporary Fleet needs a published console release (0.479.0 or later) in the server's release
  store before the PIN page offers the download.
