# v0.450.0 - TronForged 0.450.0 - only updates the shop owner signed

## TronForged 0.450.0 - only updates the shop owner signed

### Updates are signed

- **Every release is now signed with the shop owner's release key**, kept offline on a USB stick. Each release carries a signed statement naming the exact console and server programs.
- **Every PC checks it.** The shop server refuses to pull or accept a release that key did not sign. Every console checks the signature again before it installs an update, so a shop server that was broken into still cannot push the fleet a program the owner never made. The Server Console checks it before it updates the server program, and the installer checks it before it updates itself.
- **Rolling out to every PC is an administrator's decision.** New releases still go to the canary PCs automatically. Once a canary confirms a release and it has run 24 hours without a problem, it is marked ready - and waits. The rest of the shop gets it when an administrator presses **Roll out to all PCs** (Server Console, Settings, Console updates).
- **Releases need a full-access administrator.** Pulling, publishing and rolling out releases, and changing the update feed and rings, need full access; an account that only manages users can no longer do them.

### Data Migration

- **Start transfer now opens the transfer screen straight away on the old PC**, showing that it is getting ready, then that it connected to the new PC, then the files moving with the time left. The new PC shows its restore point and then waits for the old PC.

### What to do

- Update the shop server and the consoles as usual. This release itself is signed; from now on, PCs on 0.450.0 or later install only signed releases.
- If a server program you built yourself is pinned (serverExeSha256), the pin still works.
