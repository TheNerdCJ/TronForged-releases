# v0.449.9 - TronForged 0.449.9 - .NET 10, PowerShell 7 and PawnIO

## TronForged 0.449.9 - .NET 10, PowerShell 7 and PawnIO

This release moves TronForged onto .NET 10 and makes its two Microsoft prerequisites required.

### What changes for your shop
- **One self-contained program.** TronForged.exe now carries .NET 10 inside it, so it starts on any supported PC. It is about 77 MB, up from about 8 MB. The first update to this version is the large one.
- **.NET 10 and PowerShell 7 are required, and installed for you.** At setup, and whenever the console starts, TronForged makes sure the .NET 10 Desktop Runtime and PowerShell 7 are installed for all users. If either cannot be installed, a page explains why, shows where the log is, and offers Retry. Windows PowerShell 5.1 is used only to install PowerShell 7 and for recovery in Safe Mode.
- **Unattended PCs fix themselves.** A PC nobody is signed in to installs the prerequisites on its own and reports the result.
- **Installers come from your shop server.** Your shop server downloads the official installers, checks their signatures and checksums, and keeps them up to date. PCs fetch them from the server first. Each file is checked again before it runs, and it must be the right product at the minimum version.
- **PawnIO sensor driver.** It is installed on every PC so TronForged can read hardware temperatures, fans and voltages. If it cannot be installed, TronForged still runs and shows the reason and a Retry button in Settings > Prerequisites. You can remove it from Windows' installed apps.
- **Connect first, then prerequisites.** On a new PC you enter your shop server's address and pairing code first; the prerequisites install after that.
- **Failures reach your server.** When a prerequisite fails, the PC sends the reason and a short, scrubbed part of its log to your shop server. Reports are limited in size and in how many each PC can send per hour. They appear first in the field digest export and in Analyze fleet health, with likely causes and next steps. The Server Console shows how many PCs are blocked.
- **Antivirus: detect and tell.** TronForged never changes antivirus settings by itself. If the antivirus blocks TronForged or PawnIO, the technician sees what was blocked and by which product. A technician can add an exception for TronForged's own signed program only. This is recorded in the audit log, and the exception is removed if the file changes.
- **Minimum Windows:** Windows 10 version 1607 or newer, or Windows Server 2022. Older versions are refused at install.
- **Retired:** the .NET Framework 4.8 version of the console, and the planned WinPE rescue image. Leftover files from the old version are cleaned up on first start, and pinned shortcuts are moved to the installed program.
- **The SYSTEM helper** (the part that lets remote control reach the sign-in screen and administrator prompts) now runs on .NET 10. It is installed once the .NET 10 runtime is present; until then the previous helper stays in place.

### Before you update
- The update is about 77 MB. A shop server on a slow connection (under about 2 Mbit/s) may need more than one try to download it from the release feed.
- Safe Mode: if a prerequisite is missing, restart Windows normally to install it.
