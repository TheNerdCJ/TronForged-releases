# v0.449.22 - TronForged 0.449.22 - Data Migration progress and sign-in, Windows 11 on unsupported PCs

## TronForged 0.449.22 - Data Migration shows progress on both PCs and creates the customer's sign-in; the Windows 11 upgrade on unsupported PCs

### Data Migration

- **Both PCs show what is happening.** A large line says what is going on now ("Sending files to NEW-PC", "Receiving files from OLD-PC"). Under the bar: how much has moved, about how long is left, and the speed, with the file it is on. While the new PC sets things up, both PCs show each step, for example "Installing 7zip.7zip with winget (2 of 5)" - the old PC shows it as "On NEW-PC: ...".
- **The new PC can create the customer's sign-in.** In Whose data on the new PC, choose "New PC: create the old PC's user here". When the files arrive, the new PC creates a local user with the old PC's user name (an administrator, with no password yet - the customer chooses one at the first sign-in), and the files, settings and programs go into it. After a restart it is on the sign-in screen. If the new PC already has a user of that name, the files go into that user.
- **Start transfer no longer seems to do nothing.** It says "Starting the transfer..." straight away, then each step; once connected it says it is waiting for the new PC to make its restore point. A problem that stops the transfer is now said, instead of the page staying on "Reading the settings...". The old PC no longer waits forever for a new PC that stopped.

### Windows 11 on an unsupported PC

- **In-place upgrade now gets past Setup's hardware check.** In ISO Files, In-place Upgrade with a Windows 11 image asks whether to skip the hardware checks (TPM, Secure Boot, processor model). Answer Yes on a PC Windows 11 does not support: Setup then runs without them. Its windows say Windows Server; Windows 11 is what installs, and Keep personal files and apps still works.
- **The processor limit is said first.** Windows 11 version 24H2 and later need a processor with SSE4.2 / POPCNT; no setting gets past that. On such a PC the console says so before Setup starts, and suggests a 23H2 image.
- **Enable Windows 11 on Unsupported PC** now also clears the "not eligible" verdict Windows Update keeps, and tells the hardware check and PC Health Check that the PC qualifies. Undo Windows 11 Bypass removes those too.

### What to do

- Update both PCs' consoles. The shop server does not need this update.
- Microsoft does not promise updates on unsupported PCs - let the customer decide.
