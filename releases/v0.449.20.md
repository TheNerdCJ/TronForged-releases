# v0.449.20 - TronForged 0.449.20 - downloads by location, Data Migration without discovery, faster transfers

## TronForged 0.449.20 - downloads by where the PC is, and Data Migration without discovery

### Required software (.NET 10, PowerShell 7, PawnIO)

- **In the shop, over the shop's network.** When a PC is on the shop server's own network, it now gets the .NET 10 Desktop Runtime, PowerShell 7 and the PawnIO sensor driver from the shop server over the LAN, as before, and from the publisher only when the shop server cannot provide them.
- **Away from the shop, from the publisher first.** When a PC is somewhere else (a customer at home, or a PC that cannot reach the shop server), it now downloads them from the publisher's own site first, so customers no longer pull large installers through the shop's internet upload. The shop server is the fallback when the publisher's download fails or does not verify.
- **The shop server decides where the PC is**, by the same rule as the app cache: the PC must reach it directly from one of its own networks.
- **Every copy is still checked on the PC** against its publisher's signature before anything is installed, whichever place it came from. A shop server copy that fails that check is refused.

### Data Migration

- **Connect directly by address.** When the two PCs cannot find each other in discovery, the new PC can now press **Wait for a direct connection**, which shows its address, and the old PC types that address and presses **Connect directly**. No shop server is needed. Both screens show a 6-digit code to compare before anything moves, and the files travel encrypted, exactly as before. Only local network addresses are accepted.
- **Two PCs with one console identity are named.** A copied or imaged installation makes two PCs look like one to the shop server, so they can never see each other in discovery. The page now says so, and asks you to enroll one of them again or connect directly.
- **Save to USB drive works without a second PC.** Before, the USB route waited for a paired new PC to report its free space, so the transfer could not start. Now the page shows the total and **Save to USB drive** is the action. A drive that is too small is refused, with the shortfall, before anything is written.
- The page now says on the pairing step whether this PC is the old PC or the new PC.
- **Faster transfers.** Each file is now read once on each PC instead of three times, so large moves spend much less time on disk before and after the copy. A dropped connection is retried for as long as the transfer keeps making progress. A file a program holds open is skipped and listed, and the rest carries on.
- **Discovery is steadier.** A PC that closed the page no longer lingers in the other PC's list. A dropped connection to the shop server is retried instead of ending discovery. Pressing Discover again frees a pairing nobody confirmed. The empty-list message names the shop server, so you can check both PCs use the same one. While waiting for a direct connection, other network traffic no longer ends the wait.

### What to do

- Update the shop server to this version. Until it is updated, consoles keep the old order (the shop server first), and the warning about two PCs with one console identity does not appear. The direct connection works with any server version.
- Not yet tested on real hardware.
