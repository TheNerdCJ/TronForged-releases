## v0.422.0 - the remote session gets a toolbar, and Ctrl+Alt+Delete finally works

Open a remote session and there is now a strip of controls along the top of the window.
Two things live on it, and both were things a technician simply could not do before.

### Ctrl+Alt+Delete

**Commands > Ctrl+Alt+Delete.**

You have never been able to do this. Pressing those three keys on your own keyboard sends
them to **your** PC - Windows takes that combination before any program can see it - so the
customer's machine never hears about it. And Windows deliberately refuses to accept
Ctrl+Alt+Delete as ordinary typed input on the far side either. That refusal is the whole
point of the sequence: it is how you can trust that a sign-in box really is Windows' own.

So it is sent as its own command, by the **full-control helper** - the piece that already
lets you answer administrator prompts and see the lock screen. A PC without a running
helper says **"Ctrl+Alt+Delete needs the full-control helper on this PC"** rather than
doing nothing, and the strip beside the buttons tells you what happened either way:
whether the PC switched to its security screen, or whether something stopped it.

**One Windows setting changes, and you should know about it.** Windows requires a policy
called *software Secure Attention Sequence* to be switched on before any program at all may
do this. It is off on a stock Windows, so the helper install now turns it on - otherwise
this would be a button that quietly failed on every machine you own. Three things about
that, deliberately:

- whatever the setting was before is **recorded, and put back when the helper is removed**
  (and deleted outright if there was nothing there before);
- a PC that already permitted it is **left completely alone**;
- if a customer had it set for an accessibility tool - an on-screen keyboard for someone
  who cannot hold three keys at once - **that keeps working.** The setting is added to, not
  replaced.

It is named in the consent text a customer agrees to, and in the licence.

### Which of the customer's screens you are looking at

**Screen > pick one.**

Until now every remote session showed you **all of the customer's monitors stitched into
one picture**. On a two-monitor desk that is half the window wasted on a screen you are not
working on - and worse, the picture-quality budget is a cap on the TOTAL width, so two
1920-wide monitors arrived at roughly 683 pixels each. That is too soft to read a stop
code, a licence key or a Device Manager error - which is most of what a remote session is
opened to read.

Pick one screen and it gets the whole budget. The difference is immediate.

The menu lists what that PC reports - numbered, with each screen's resolution, and the main
one marked - and it follows the PC rather than your click: if a monitor is unplugged
mid-session the picture falls back to the whole desktop instead of showing a rectangle that
is no longer on any screen. A single-screen PC says so and the menu stays shut.

### Also on the bar

**Commands** also carries Task Manager (Ctrl+Shift+Esc), Lock (Win+L), Run (Win+R), File
Explorer (Win+E), Switch window (Alt+Tab) and Close window (Alt+F4). These are ordinary key
combinations, but several of them would act on **your** PC if you typed them, so they are
worth a menu.

The bar takes its own strip above the picture rather than floating over it, so a click
meant for the customer's screen can never land on a menu by accident. **F12** still shows
the connection stats.

### Worth knowing

**A PC that has not updated yet is not broken.** These are new requests, and an older
machine does not answer them: the Screen menu says it is still asking rather than offering
a choice it cannot deliver, and Ctrl+Alt+Delete reports that the helper is too old. Both
sort themselves out when that PC updates.

**To get Ctrl+Alt+Delete on a machine that already has the helper**, re-install the helper
from **Settings > Remote access to this PC** on that PC, or let it update - the Windows
setting is turned on by the install.

**Not yet tried on real hardware.** The toolbar, the screen switching and the
Ctrl+Alt+Delete path are built and tested, but a real two-monitor customer PC and a real
locked machine are still on the bench list.
