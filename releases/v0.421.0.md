# v0.421.0 - a quality release - nothing you can see changed

## Nothing you can see changed

This is a quality release. The console behaves exactly as v0.420.0 did: no screen
moved, no setting changed, nothing was added or retired. It is published so that
every shop runs the same build the source tree does.

## What changed

TronForged is built from 44 separate projects. Only three of them treated a
compiler warning as something that stops the build; the other 41 printed their
warnings and carried on. Those 41 had accumulated 119 unread warnings between
them. All 119 are now cleared, and every project in the product now refuses to
build while a warning remains.

Most of that was noise. Three items were not, and are fixed in this release:

* A self-test that could never fail. It compared a value against "nothing" when
  that value can never be nothing, so it reported success without testing
  anything.

* A crash in the checker that validates the repair-fix catalogue. A malformed
  entry made the checker fall over instead of reporting the entry as bad - so a
  bad catalogue could look like a broken tool rather than a bad catalogue.

* A dependency that stopped being needed several releases ago and was still
  being carried.

Two places where the code claimed a value was always present, while the code
immediately below it checked for that value being absent, were corrected to say
what they actually do.

## Why this was worth a release

The previous release found a warning that had been printed on every clean build
for months and read by nobody. It was the visible end of a test that had quietly
stopped testing anything. Making warnings fatal everywhere is how that stops
being possible: from this release on, an unread warning cannot reach a build.

## Upgrading

Nothing to do. Enrolled consoles update themselves from your shop server as
usual, and no settings change.
