## v0.394.0 - a server that has stopped updating says so on the front page

The previous two releases put the reason your consoles were not updating on the Updates page.
This one puts it on **Status** - the page the Server Console opens on - because a warning only
helps if it is where you already are.

### The new row

Status now carries a **Release feed** line, and it says one of four things:

- **BROKEN** (red) - a real failure, quoting the server's own reason for it, plus the newest
  version actually sitting in your catalog so you can see how far behind you are at a glance.
- **Not the product's feed** (amber) - the server is reading somewhere else, so releases will
  not arrive.
- **Automatic updates are paused** (amber) - not a fault, but worth saying out loud. A shop
  that paused the pipeline months ago and forgot looks exactly like one that is broken, until
  something tells you which.
- **Healthy** - the feed it is reading and the newest version it holds.

Each of the first three points at **Settings -> Console updates**, where the fix is.

The row goes quiet on its own once the problem is resolved - it reads the live state, not a
stored complaint, so a feed you have already fixed stops reporting itself as broken without
anyone having to clear anything.
