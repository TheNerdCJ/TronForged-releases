# v0.449.10 - TronForged 0.449.10 - the Repair expansion

This release follows v0.449.9. It is the Repair expansion: every service run now keeps a record of what it did and an undo record of what it changed, every repair is one piece of code shared by the automated service and Windows Fixes, the stages report honestly what they did, and there are new repairs, tweaks and report items. The licence changes to describe what a service now does (below).

**Not yet tested on real Windows.** The steps in this release that change Windows - the repairs, the undo record and its revert, the debloat and tweaks, the Prep, Patch and Optimize changes and the new Windows Fixes - and the new reading of Windows' own crash records have been checked by tests on recorded answers and test stand-ins only. They have not yet been run on a real Windows PC. Try this release on a test PC before you use it on customers' computers.

## The run record and the undo record

- Every service run now keeps a run record (in a folder only administrators can open) listing each step, what it found and why a step was skipped. It continues across the restarts a run makes (Safe Mode, updates). If it cannot be written, the run log says so; the service report is unaffected.
- The run record is shown as two pages: a full technician page kept with the record, and a customer page beside the service report that summarises threats by kind, what was removed and what still needs attention. The customer page never shows a Windows user name: every path is shown as C:\Users\<user>\...
- New: an undo record. Before TronForged changes a setting it records what the setting was - registry values, service start types, scheduled tasks, the power plan, the firewall rule set, the hosts file, the proxy, DNS servers, browser notification settings and jump lists - in the run's protected folder.
- New Windows Fix: **Revert this run's tweaks** (System Repair). It puts back what the newest service run recorded, newest change first. A setting that something else has changed since the run is reported and left alone; it is never overwritten. Files the run deleted and apps it removed are not in the undo record; the restore point covers those.
- The four Windows Fixes that lower security to get an old printer or NAS working (Shared-Printer Error 0x0000011b, Disable Windows Protected Print, Restore NAS/Share Access, Add Shared Printer past Driver Prompt) now record the value they replace. Three new fixes put it back: **Undo: Shared-Printer Error 0x0000011b**, **Undo: Disable Windows Protected Print** and **Undo: Restore NAS/Share Access**. On a PC with no record, each sets Windows' secure default instead.

## Repairs: one implementation, verdicts read back

- Each repair is now one piece of code shared by the automated Repair stage and the matching Windows Fix, so both say the same thing and both can be undone the same way. A repair says "Fixed" only after it has checked the PC afterwards.
- Automated service no longer resets the Windows Firewall. It turns the firewall back on if it was off. **Reset Windows Firewall** in Windows Fixes saves the old rules first and keeps TronForged's own remote-support rule; Full Network Reset no longer resets the firewall.
- Custom hosts-file entries are turned off by commenting them out, never deleted, and the old file is kept.
- Automated service resets the internet proxy only when Disinfect found a hijack, so a business proxy is left alone.
- The WMI repair checks, salvages and only then resets the repository, and always leaves the WMI service running. The Windows Update reset no longer re-registers system files or rewrites service permissions.
- DISM runs only when Windows reports damage, and the SFC result is read from what SFC actually wrote.
- Windows Fixes merged duplicate entries: Rebuild Icon Cache, Reset Windows Update Components, Repair WMI Repository, Repair Temp-Profile Loop and Rebuild Windows Search Index each replace two or three older entries. "Shell repair (black screen fix)" was removed; use Winlogon Repair, which now finds Windows on any drive.
- Fixes no longer assume Windows is on C: (Check Disk, Disk Health Scan, the boot-loop pair, Rebuild EFI Boot Files, Clear GPU Shader Caches). Rebuild EFI Boot Files picks a free drive letter.
- Repair Recovery Environment re-enables Windows RE where it is and checks that it came back on, instead of pointing it at a folder that is empty on Windows 11 24H2.
- The Windows Update, Network, Audio and Printer troubleshooters now open Get Help (Windows 11 24H2 removed the old ones).
- 44 more fixes now check their result, and every fix that changes a setting without an undo record says so in its description.
- The file-association repair now restores the whole table (.exe, .lnk, .reg, .bat, .cmd, .com, .scr, .inf, .msc and folders) in one pass.

## New repairs (Windows Fixes > Repair Additions)

- Remove firewall rules for programs that are no longer installed (TronForged's own rules and rules for unplugged drives are kept), show Start Menu and desktop items an infection hid, rebuild missing Safe Mode keys, fix a missing CD/DVD drive caused by leftover filter drivers, check COM+ registration (read-only), restore New > Text Document and New > Folder, restore the default printer ports, re-enable a switched-off page file, and clear the certificate URL cache.
- **Microsoft Defender Offline Scan** - asks first, then restarts the PC into Microsoft's offline malware scan.
- In the Repair stage these repairs run in the Full and Combo profiles; the other profiles leave them off. Minimum diagnostic data and Delivery Optimization on the local network only stay off in every profile (they are Windows Fixes a technician chooses).

## Clean-up, debloat and tweaks

- A stage that recorded a failure now always shows a Warning. Before, Clean-up, Debloat, Optimize and Wrap-up could show green over a failed step.
- Debloat checks its work: it asks Windows again which apps are still installed and reports only the apps that are really gone. It no longer removes Media Player, Films & TV, Get Help, the Microsoft 365 app or Clipchamp, and it removes a third-party app only when it came with Windows or the computer's maker; a copy the customer installed is kept.
- After debloat, Windows is told not to reinstall promoted apps or show suggested apps, for every user of the PC and for new users. Plugging in a mouse, keyboard or headset no longer installs the maker's companion app automatically.
- The website-notification reset removes only sites the customer allowed; blocked sites stay blocked, and each site is named. A browser open during an unattended run is no longer closed under the customer; the step is skipped and says why.
- The privacy sweep keeps pinned jump-list items. Crash dumps and error reports from the last 30 days are kept for diagnosis, and Prefetch is no longer emptied.
- Space freed is counted after files are deleted. Before the clean-up deletes anything, the run record now keeps how much each category is about to free.
- New Windows Fixes (**Tweaks & Privacy Choices**): minimum diagnostic data, Copilot and Recall off by policy, a Windows Update security preset and Microsoft defaults, stop firmware installing programs (WPBT, with a warning), Delivery Optimization on the local network only, and a reset for another debloat tool's leftovers. Each is recorded so it can be reverted.

## Prep, updates, scans and Optimize

- Before a service starts, TronForged checks whether Windows is waiting to restart. If the profile allows restarts, it restarts first and carries on after sign-in; otherwise the report warns. It never restarts twice for this.
- The service warns when less than 10 GB is free. When there is not enough room for a restore point, the oldest restore points (never one from this visit) are removed and the space Windows reserves for them is limited to 10% of the drive; this is noted in the run record because it cannot be undone. The restore point is confirmed by reading it back.
- TronForged no longer changes the PC's sleep or screen-off settings during service; it asks Windows to stay awake only while the service runs, and the power settings saved at the start are put back at the end, also when a technician stops the service early.
- Windows Update runs in its own PowerShell process with a 180-minute limit, is searched once (also covering Microsoft products such as Office), never installs a feature update, and uses Windows Update drivers only when the PC maker's tool (Dell, Lenovo, HP) did not run. Microsoft Store apps are updated too.
- Emptying the Windows Update download cache and cleaning the component store now happen after the updates, not before them; the cache is left alone while a restart is pending.
- The Microsoft Safety Scanner now runs before the Malicious Software Removal Tool, which is skipped when the Safety Scanner finished its full-signature scan. Every whole-disk scan now has a time limit that grows with the data on the PC; none gets less time than before.
- Optimize no longer touches the drive a system image is being written to, or the drive TronForged runs from. SSDs get TRIM; hard disks are defragmented only when Windows recommends it.
- The Windows support check uses a dated table of versions and editions; an unknown build is reported as unknown, never as supported.

## Disinfect

- Disinfect reads what each scanner found from that scanner's own log for this run only, and records every detection in the run record. Threats found and threats removed are counted separately; a threat a scanner only reported, or could not remove, is shown as still needing attention.
- Microsoft Defender counts only what it detected during this run. In the Safe Mode pass Defender is skipped (it does not run in Safe Mode) and the report names the scanners that actually ran.
- A system proxy is judged as a hijack or as the business's own proxy.
- Kaspersky's Virus Removal Tool has been removed (it was only ever shown as the vendor's page). An older profile's setting for it is ignored.
- The startup audit now also looks at Winlogon's Shell and Userinit, Image File Execution Options debuggers, AppInit_DLLs, WMI event consumers, the 32-bit Run keys and services that start from a folder ordinary users can write. These are flagged for review; nothing is changed.
- ClamAV is unpacked into a new folder and moved into place only when complete.
- **HitmanPro stays a manual tool** on the Tools tab; no service run starts it. Its free scan and trial do not license a business to use it on customers' computers, so buy a Sophos licence before using it for paid work.
- **Everything** (voidtools, MIT licence) is on the Tools tab under Cleaning & Debloat.

## Report items and conveniences

- The Diagnostics stage reports, for information only: whether Secure Boot is ready for Microsoft's 2023 certificates, whether Windows is activated, drive health from Windows' storage counters, whether the clock is syncing, and free space on the system drive. These never change the PC or the health score; a fact that cannot be read says "unknown".
- Diagnostics reports when another debloat tool has left Windows Update, the Microsoft Store or Delivery Optimization blocked.
- The run record shows the programs installed, removed or updated during the service, the space to be freed in each category and the DNS test results. The customer page does not show server addresses or user names.
- New Windows Fixes (**Quick Toggles & Extras**): Show File Extensions, End Task on the Taskbar, Detailed Blue Screen and NumLock On at Sign-in, each recorded so it can be reverted; a DNS Speed Test that changes nothing; Switch to the Fastest Public DNS (asks first, old DNS recorded); Preview Space to Be Freed; and Back Up and Clear Event Logs (a log is cleared only after its backup checks out).

## Software health for your shop server (fleet analyzer)

- The shop server's software-health report now covers much more: Windows Fixes that failed, repair steps that failed, timed out or were skipped (and why), console freezes longer than 5 seconds, remote sessions that failed or dropped (and at which stage), the shop server's own errors, update rollbacks, and crashes or hangs that Windows itself recorded for TronForged, including the full-control helper.
- New in the Server Console: Settings > Software health > **Export for fixing...** writes fleet-digest-<date>.md and fleet-digest-<date>.json, one entry per problem, with how many PCs, which versions, first and last seen, whether it is new or came back, and up to three samples. Paths, user names and addresses are removed.
- The report now lists start-up time, the time each repair stage takes, and how long the server takes to answer, per version, and flags a version that got slower.
- Diagnostic records are no longer sent twice, or lost, when the console window, the before-login service and a service run write at the same moment. A PC that had to drop old records now says how many.
- Each record now says which console and which part sent it, the Windows display language, and whether the PC was in Safe Mode. Crash and freeze reports include the last 20 named actions (which tab was opened or which button was pressed); nothing you type is ever included.
- Disinfect now reads scanner logs correctly whatever their line endings, so a Safety Scanner or AdwCleaner removal is no longer reported as only "found".

## Your shop's catalogue

- Updated fixes, debloat lists, profiles and tool lists now reach consoles that are already installed. Each catalogue file is replaced on update only if your shop has never edited it. A file your shop has edited is kept and reported (Settings > Catalogue, where **Reset to shipped** replaces it). Your branding, sign-ins, enrolment and console settings are never touched.
- The two scanner settings in Settings are now saved with the console's other settings, so a console whose Settings were saved still gets scanner-list updates.
- Every place the product compares versions was checked with the two-digit 0.449.10 against 0.449.9, so updates are offered and ordered correctly.
