# v0.457.0 - TronForged 0.457.0 - Safer repair runs

## TronForged 0.457.0 - Safer repair runs

This release makes the repair engine safer to leave running: one run at a time, no hidden questions after a restart, programs that cannot hang for ever, and two clean-up mistakes fixed.

### One repair run at a time
- Only one repair run now works on a PC at a time. If a second run starts while one is working - for example when someone else signs in and Windows fires the automatic resume, or a run is started from the console while the before-login agent is running one - the second run writes one line to its log and stops without changing anything.
- A resume after a restart never waits on a question nobody can see. If it finds no unfinished run to continue, it turns Safe Mode and the automatic resume off and stops. If the PC is still in Safe Mode, restart it.
- If a run started from the console stops because another run is already working, the console may say "Restarting to continue". The run's log says what really happened. Let the first run finish.

### PowerShell modules
- A repair run, and every script the console starts, now loads PowerShell modules only from the Windows and Program Files module folders, never from the signed-in user's own Documents folder.
- The two modules the Patch stage installs from the PowerShell Gallery (Microsoft.WinGet.Client and PSWindowsUpdate) are loaded only when every one of their program files carries a valid digital signature. If they do not, winget is installed from Microsoft's checked App Installer package instead, and the Windows Update step is reported as failed with the reason.

### winget
- The Windows fixes that use winget (Update All Apps, List Available App Updates, List Installed Apps, Refresh winget Sources, Reset winget Sources, Reinstall Win Terminal, Repair Photos/Calc/Snip) now run only Microsoft's own App Installer winget, the same rule as the Apps page. A winget.exe anywhere else on the PC is never run. When there is none, the fix does not run and says why; Repair Photos/Calc/Snip still resets its apps. Use Repair winget to bring winget back.
- The console now keeps hold of the winget file it checked until winget has started, so it cannot be swapped in between.

### Programs that could hang
- The programs the console and the shop server start for their own work (service, firewall, folder permission and scheduled task tools, PowerShell, the server's database tools) now stop when their time limit runs out instead of waiting for ever. The Visual C++ runtime install is given 15 minutes.

### Other fixes
- Reinstalling TronForged from a downloaded copy is no longer replaced on the next start by an older update that was waiting to be applied.
- TempClean no longer deletes working shortcuts whose path contains square brackets, such as `[1]`.
- TempClean now keeps Outlook's attachment cache (`Content.Outlook`), which can hold the only edited copy of an attachment. The report says it was kept.

### What to do
- Update the shop server, then the PCs.
- Nothing else is needed. If a PC is left in Safe Mode after a repair run, restart it.
- If the Patch stage reports that a PowerShell Gallery module was refused, the run carries on. Run it again later, or let the next scheduled maintenance try again.
