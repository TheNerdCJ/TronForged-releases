## v0.389.0 - internal checks, corrected

This release changes nothing you will see while using TronForged. It fixes two of the
product's own self-checks that were reporting more confidence than they had earned.

- **The release publisher no longer fails on a timing race.** GitHub takes a few seconds to
  settle after a release is published, and the publisher was reading back the result
  immediately - so a successful release could be reported as a failure. It now waits for the
  feed to catch up, while still failing straight away if something genuinely went wrong.
  Nothing about what it verifies has been relaxed: the four files, their sizes and both
  checksums are still fetched back and compared, without a token, exactly as a customer's
  installer would read them.
- **Two shipped scripts were never being checked.** TronForged verifies that every script it
  ships can run on the PowerShell that comes with Windows - the version every PC has. That
  check was looking at a folder rather than at the packaged product, and two scripts that
  ship live outside that folder. They were correct, and are now covered.

Assets: `TronForged-0.389.0.exe` + `.sha256`, `TronForged.Server-0.389.0.exe` + `.sha256`.
