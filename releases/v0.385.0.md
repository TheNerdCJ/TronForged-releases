## v0.385.0 - accented names no longer break the virtual-machine boot test

If a technician gave a boot test a name containing an accented character - a customer's name,
a machine name, a folder under an accented Windows profile - the test could finish, report
success, and leave a running virtual machine and several gigabytes of disk behind on the
machine it was run from. Its own clean-up looked for a name that no longer matched.

- **Every script TronForged writes for itself is now written in a form both PowerShell
  versions read identically**, so a name with an accent in it survives from end to end.
- The same correction was applied to the five other places the product writes a script
  before running it, including Windows Fixes, ISO preparation and driver backup.

Nothing about how you use these features changes.

Assets: `TronForged-0.385.0.exe` + `.sha256`, `TronForged.Server-0.385.0.exe` + `.sha256`.
