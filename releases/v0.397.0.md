# v0.397.0 - One console at a time

## v0.397.0 - one console at a time

**Double-clicking the desktop shortcut while a console is already running now brings that
console to the front instead of starting a second copy.**

### What was wrong

Closing the console window does not exit it - it tucks itself into the notification area and
keeps running, which is deliberate so remote support and monitoring carry on. But it also
disappears from the taskbar, so the natural thing to do next is double-click the desktop icon.
That started a brand-new copy alongside the one still running.

Two copies on one machine fight over things only one of them can hold: the remote-access
port, the ownership of the before-login agent, the saved sign-in cache. The second copy's
remote access would fail to arm, and in some cases it would repeatedly restart the agent
service on a machine where nothing was wrong. It looked like "the second console cannot see
the server". It could - it just could not do anything useful once it got there.

### What changed

Only one console runs per signed-in session. Launching another - from the desktop, the Start
Menu, or anywhere else - asks the running one to show itself and then quietly exits. The
notification-area icon already did this; now the shortcut does too.

Three things this deliberately does NOT do, because each would have caused a worse problem:

- It does not refuse instantly. When the console updates itself, the new copy starts while
  the old one is still shutting down. The new copy waits for the old one to finish rather
  than giving up, so an update can never leave you with no console at all.
- It does not block a second Windows user. A technician connected by Remote Desktop while
  someone is at the physical machine gets their own console, as before.
- An auto-started console (the one that opens hidden at logon) never pulls itself in front
  of somebody who is working.

### Worth knowing

If you have been in the habit of closing the console and re-opening it from the desktop, you
will now simply get the same console back, with everything as you left it.
