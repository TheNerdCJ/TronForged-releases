# v0.492.0 - Remote in by RDP or TronForged, and a virtual screen for PCs with no monitor

# TronForged v0.492.0

Choose how you remote in - Windows' own Remote Desktop or TronForged's remote desktop - and give a PC with no monitor a
screen to show.

## Remote in: By Remote Desktop (RDP) or By TronForged RDP

- **Remote in is a menu now.** On the Fleet and remote page, **Remote in** (it has a down arrow) offers **By Remote
  Desktop (RDP)** first and **By TronForged RDP** second. A fleet tile's right-click menu has the same two items where it
  had **Remote control**. Nothing connects until you pick one.
- **By TronForged RDP** is TronForged's own remote desktop, exactly as before.
- **By Remote Desktop (RDP)** connects the same way and, as soon as you are in control, opens Windows' own Remote Desktop
  through the encrypted session - just as **Commands > Open Remote Desktop (RDP)** does - with the same confirmation if
  Remote Desktop is off on that PC. The TronForged window then steps out of the way (it stays connected underneath). It
  is the better choice for a server with no monitor.
- If the PC cannot do it (an older TronForged, or you are only watching), the window says why and stays open, so you are
  never left with nothing. A Windows Home PC shows the item greyed: Windows Home has no Remote Desktop.
- **Remote Desktop opens at 1920x1080 in a window** and the far desktop follows the window: maximise it or go full
  screen and it takes that size, 4K included.

Only your console needs this version; nothing changes on the customer's PC or the shop server.

## A virtual screen for a PC with no monitor

A PC with no monitor attached (a server in a rack, for example) has no screen for Windows to draw, so TronForged's remote
desktop has no picture. Now, when the remote desktop says Windows reports no screen on that PC, an **Add a virtual
screen...** button appears, and the **Commands** menu has **Add a virtual screen...** (and **Remove the virtual
screen...** once one is on).

- **What it is.** The open-source Virtual Display Driver (by VirtualDrivers, release 25.7.23, MIT licence, signed by
  SignPath Foundation) ships inside TronForged. It adds one virtual monitor, 1920x1080 by default, up to 3840x2160. It
  is a user-mode display driver, not a kernel driver.
- **What changes on the PC.** A confirmation lists it first. TronForged checks every file of the driver against the
  fingerprint built into TronForged and the driver's signatures, keeps them in a folder only administrators can change,
  and installs it with Windows' own tools. Windows is told to trust the driver's publisher, SignPath Foundation, only
  for the length of the install; that trust is taken away again straight after, and nothing else that publisher signs is
  trusted. The virtual screen stays, across restarts, until it is removed from the same menu.
- **Who.** Only the technician in control of a PC enrolled with the shop. Never a technician who is only watching, and
  never in a one-time support session.
- **Recorded.** Each add and remove is written to that PC's remote audit log (who asked, what was there before, and the
  outcome) and to the shop server's audit log (who asked, for which PC). The shop server needs v0.492.0 for that record;
  an older one says it does not record that action, and the change itself still happens.
- **Uninstalling TronForged removes it too.** An uninstall first takes away a virtual screen TronForged added (the
  device, its driver and its folder), before anything else. If that cannot be done, the uninstall says so and keeps the
  driver's locked folder rather than leave it to be replaced.

The PC needs TronForged v0.492.0. With an older version nothing new is offered and nothing else changes.

## Licence

- The licence gains section 10.15, which covers the virtual screen: who may add one, that its files are checked before
  it is installed, that Windows trusts the driver's publisher only for the length of the install, that it stays until
  it is removed or TronForged is uninstalled, and that each addition and removal is recorded. Sections 5.3 (the drivers
  TronForged installs) and 10.5 (what is recorded) name it too, and the driver is listed among the components shipped
  inside TronForged (Schedule A, Part 1). The privacy notice is unchanged.

## Known limits

- The virtual screen has not yet been tried on real hardware: it has been tested with stand-ins for Windows. A Windows
  Server with no monitor and Windows 11 Pro are the first places it will be checked.
- Choosing either Remote in option on a PC you are already connected to hangs up that session, as Remote control did;
  choose again to connect.
