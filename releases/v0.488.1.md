# TronForged v0.488.1

## Fixed

- **Remote desktop to a server with no monitor now says why the screen is black.** When nobody was signed in on a
  Windows Server with no monitor attached, the viewer showed only "The screen has stopped being captured on this PC",
  which sent you looking for a broken helper. TronForged had already detected that Windows reports no screen, but that
  message was immediately replaced. The viewer now keeps it: Windows reports no screen on that PC, and you need a
  monitor, a display emulator (dummy plug) or the server's management card display to see it. If the helper on that PC
  really stops working, you are still told the capture stopped.
