# TronForged v0.493.0

Keep the shop server's own PC up to date - Windows updates, apps, temp files - from its Server Console, and know when
it needs a restart.

## A Maintenance page for the server box

- **Where.** On the PC that hosts your shop server, the Server Console has a new page: **This server > Maintenance**.
  Sign in as an administrator to use it.
- **What it does.** Three things and no others: it installs Windows updates, updates the apps winget can update, and
  cleans temp files (Windows' and every profile's temp folders, old crash dumps and error reports, thumbnail and shader
  caches, the Delivery Optimization cache).
- **What it does not do.** It never restarts the PC by itself. It does not debloat, scan for malware, repair,
  optimise, or update drivers, the manufacturer's tools or Store apps. It does not update TronForged itself (that is
  still Settings > Console updates). It never touches the shop server's data, database, snapshots or backups.
- **On a schedule, if you want one.** The schedule is off until you turn it on: tick **Run maintenance on a schedule**,
  choose weekly (a day) or monthly (day 1 to 28) and an hour, and press **Save schedule**. It runs at that time, in
  the server's own time, and a time missed while the PC was off runs when it is next on. If Task Scheduler does not
  answer when the page opens, the page says so and will not save until it has read the schedule.
- **Or now.** **Run maintenance now** starts the same run at once (save the schedule once first). While it runs the
  page says *Running since ...*; afterwards *Last run* says how it went: *ok*, *failed* and what failed, *timed-out*
  (after 225 minutes), or *refused* and why it did not start. **Open the log** shows every step.
- **Windows Server without winget.** Windows Server 2019, and some Windows Server 2022 installs, have no winget. The
  run still installs Windows updates and cleans temp files, and says *ok - winget is not available on this Windows*.

## The restart banner and Restart now

- When Windows on the server's PC needs a restart to finish installing updates, everyone in TronForged's
  **Administrators** group sees a banner: *The shop server's PC needs a restart to finish installing updates.* It is
  at the top of the Server Console and in the technician console, it cannot be closed, and it goes away by itself once
  the PC has restarted. Away from the server box it adds *Restart it from the Server Console on the server box.*
- On the server box the banner and the Maintenance page have **Restart now...**. It first asks the shop server whether
  anything is going on (a remote session, a backup or other transfer, a patch install). If something is, or the
  server cannot say, it tells you and asks *Restart anyway?*. Then Windows restarts after one minute, and the shop
  server is back a few minutes after Windows starts. While it is asking, the button is greyed out, and a second
  press of either Restart now... is turned down.
- Nothing restarts the server's PC unless an administrator presses Restart now.

## Who and where

- The page and Restart now are on the server box only. A Server Console opened from a technician console (Server
  administration) does not have them: the shop server program runs with too few rights to update or restart Windows.
- Turning the schedule on or off, Run maintenance now and Restart now are written to the shop server's audit log. The
  shop server needs v0.493.0 to keep that record; an older one says so and the action still happens.
- The banner needs the shop server and the console on v0.493.0. With an older shop server no banner appears.

## Known limits

- Not yet tested on real hardware: a Windows Server 2022 and 2025 bench is planned.
- The page always shows the default day and hour (Sunday, or day 1 for Monthly, at 03:00) when it opens, not the
  ones saved; the *Next run* line shows the real schedule. Check the day and hour before you save again.
- On a Windows that is not in English, Run maintenance now does not notice a run that is already going (the run
  itself still refuses to start twice), and *Running since ...* does not show.
- Restart now restarts Windows one minute later, and the page has no way to call that off yet.
- If another TronForged run is still working on the server's PC when maintenance starts, that run does nothing and
  *Last run* says *ok - the run's results file was not found* rather than *refused*.
