# v0.447.0 - For the record only - card numbers and locked data folders (superseded by v0.447.1)

Published for the record after v0.447.1. Install the latest release instead: it includes everything here and later fixes.

**This release is published for the record only.** It was replaced by v0.447.1 before it was offered as the latest release, and it is not offered as an update: shop servers, consoles and new installs never receive it. Do not install it: install v0.447.1 instead - its release notes cover everything below, and it fixes problems found here before release, among them unattended access on the day a PC updates, the installer changing the data folder when it could not copy the program, the Status page saying nothing when its card-number check found nothing, printing from the report viewer, the snapshots the card-number removal replaced, the sign-in message after 72 hours offline, places where staff could still type a card number, and what the licence said about an old BitLocker key copy.

What v0.447.0 added, on top of v0.446.0, as a security release: a card payment records only the card's brand and last four digits, text shaped like a full card number is refused in most places staff and customers type, invoices, exports and what the shop server sends to Square, the AI provider and diagnostics mask it, and the shop server looks for card numbers typed before it and can remove them. Recording a refund and voiding an invoice need a new permission, refunds. Each PC's TronForged data folder is locked to that PC's administrators and Windows itself, and reports and logs open inside the console. Offline sign-in lasts 72 hours on the shop's own PCs, is never kept on a customer's PC, and is erased when the shop server disconnects the PC. Each armed PC's unattended-access code is replaced once, a console never sends a mail password over a connection without TLS, and a repair run no longer copies BitLocker recovery keys, takes a picture of the desktop only when asked, and saves only the registry keys it changes. The licence was updated with it.
