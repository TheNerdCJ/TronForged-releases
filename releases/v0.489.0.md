# TronForged v0.489.0

Copy and paste between your PC and the customer's during remote desktop, and a service run that restarts the PC no longer looks stuck.

## Copy and paste in remote desktop

You can now copy and paste text between your PC and the customer's PC during a remote desktop session.

- While you are the technician in control, text you copy on your own PC can be pasted on the customer's PC, and text
  copied on the customer's PC can be pasted on yours. It happens by itself - just copy, then paste.
- Plain text only (no files, pictures or formatting), up to 65,536 characters at a time. A longer copy is not sent, and
  the window says so.
- The Remote Desktop window's bar shows each copy: "Copied to the customer's PC (N characters)" or "Copied from the
  customer's PC (N characters)".
- A technician who is only watching gets nothing.
- Text copied before the Remote Desktop window opened is not sent; copy it again once the window is open.
- The customer's PC records each copy in its remote access log with its direction and length. The text itself is never
  logged or stored, and it never goes to your shop's server. (A one-time support session writes no log on the customer's
  PC, so there the record of each copy lasts only while the support program runs.)
- It works once someone is signed in on the customer's PC, and in a one-time support session (Temporary Fleet) too. At
  the sign-in screen the window tells you clipboard sharing is not available there yet.
- Both PCs need this version or later. With an older version on either side nothing is shared, and everything else works
  as before.

## Fixed

- **A service run that restarts the PC no longer looks stuck.** When Windows updates needed a restart during a tune-up,
  the run did continue after you signed in again, but it works in the background, and the console's progress bar
  kept saying "continues after the restart" with Patch waiting - so it looked as if nothing had resumed. The console
  now follows the resumed run: each stage is marked done as it finishes, the stage it is working on is shown, and the
  bar says "finished after the restart" when the run is complete.
