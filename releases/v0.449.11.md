# v0.449.11 - TronForged 0.449.11 - inventory, the new-install fix, prerequisites from your server, virtual machines, Topaz pads

TronForged 0.449.11 - stock and inventory, prerequisites from your shop server, virtual machines, and form bullets.

Update your shop server first: this release adds the stock tables to the server's database.

## Fixed: new installs stopping at the prerequisites screen

- New installs on v0.449.9 and v0.449.10 could stop at the prerequisites screen because the current .NET 10 installer and PawnIO driver were wrongly refused; fixed. If a PC is stuck there now, install the .NET 10 Desktop Runtime (x64) from Microsoft and press Retry, or update to this release.

## Stock and inventory

- Keep track of the parts and products you hold at each of your shop's locations, with what is available, on hand and held, and the average cost of each item.
- New Inventory page (under Customers, for staff with stock rights): add and edit items, scan a stock label or type a SKU to find one, receive stock and move it between locations. Suppliers and Locations have their own lists.
- Print stock labels (name, SKU, price and a barcode) on the label printer you already use for customer labels.
- On a ticket, hold a part from stock for the customer; the line shows who it is held for and who held it. If the part is out of stock, the ticket shows it is waiting for a part. Release a hold to put the part back.
- Invoices: "Add held parts" adds the ticket's held parts at their price. They leave stock when the invoice is sent; voiding the invoice, or refunding with "put back in stock", returns them.
- Purchase orders: TronForged drafts orders for items that fall to their reorder point (or you draft one by hand), a manager approves, and the order is emailed to the supplier once from your shop's mailbox. Purchase orders never include customer details.
- Stock cannot be taken twice when the same invoice is sent from two places at once, and a held part cannot be put on two invoices.
- Cycle counts: count a location while the shop stays open; sales and deliveries during the count are taken into account, every difference needs a reason, and every adjustment is logged.
- ABC analysis shows which items carry most of your stock value, updated each night. It says "Not enough history yet" for the first 30 days.
- New permissions: technicians and reception can see and use stock; counting, adjusting and approving purchase orders are for administrators unless you grant them in Users & groups.
- Amazon Business ordering is switched off in this release. The Server Console has a new Stock ordering page with the switch and a place for the key (sealed on the server), but TronForged cannot place an Amazon order yet: that needs an Amazon Business account and Amazon's API approval, and a later release. Until then, purchase orders go by email.

## .NET 10 and PawnIO from your shop server

- Consoles now get the .NET 10 Desktop Runtime and the PawnIO sensor driver from your shop server first, as they already did PowerShell 7. The publisher's download is used only when the server has no copy yet or cannot be reached.
- Every console checks each installer's digital signature again before running it. A copy from the shop server that fails that check is refused rather than replaced by a download from the internet.
- The shop server's own PC installs these components from the server's own verified copies, and its Server Console can install or check .NET 10, PowerShell 7 and PawnIO from Settings.
- New in Server Console Settings: "Prerequisite installers this server serves" shows the version, size and last check of each installer, or why one is missing.
- If the server cannot download an installer, it tries again within the hour instead of the next day, and a problem with one installer no longer stops it refreshing the others.

## Virtual machines

- TronForged now installs safely on a virtual machine. The shop server, the Server Console PC and the PCs you monitor can be Hyper-V, Azure, VMware, VirtualBox, QEMU/KVM (Proxmox), Xen/Citrix, Parallels, Amazon EC2 or Google Compute Engine guests; everything installs and runs as usual, including .NET 10 and PowerShell 7.
- On a virtual machine the PawnIO sensor driver is not installed - a VM has no temperature, fan or voltage sensors to read. Settings > Prerequisites says "not needed on a virtual machine"; it is not a failure and is not retried. A PawnIO already installed on a VM is left in place.
- A Hyper-V host is still recognised as a physical PC, and a machine TronForged cannot identify is treated as physical, so nothing is skipped on a guess.
- Service runs on a virtual machine no longer report false hardware failures: drive health, battery health, Secure Boot certificate readiness, drive counters, the manufacturer's driver and firmware tool, and Optimize drives say "skipped - virtual machine" instead.
- The sensor panel and the Storage and Battery reports say when the PC is a virtual machine, and the fleet shows "Virtual machine (VMware)" (or the hypervisor's name) beside the Windows version.
- New in the guides: "Running on a virtual machine" in the README and the server setup guide.

## Forms

- Start a line with - (or *) for a bullet. The preview, the printed page, the signing screen and the signed PDF draw a real bullet, with wrapped lines lined up under the text.
- Text pasted from a word processor or web page no longer shows "?" or gets refused. Bullets, curly quotes, long dashes, non-breaking spaces and "..." are changed to plain characters, and the editor tells you what it changed.
- Characters a form still cannot print, such as accented letters, are refused with the same plain explanation as before.
- Topaz signature pads now capture: the pad is started the way Topaz's own SigWeb page starts it, the signature shows in the box live as the customer signs, and Done saves it. Settings has a new Test pad button that says "Pad works", "Pad not connected" or "SigWeb not answering", and logs\sigweb.log records each exchange with SigWeb (never the signature itself).
- Forms already signed are unchanged: their text and their PDF stay exactly as signed.
