# v0.449.16 - TronForged 0.449.16 - a leaner, stricter program

## TronForged 0.449.16 - a leaner, stricter program

A maintenance release. We went through the whole program and removed code that nothing used any more: leftovers from features that were retired, helpers that were replaced by newer ones, and a few files that only existed for tests. Less code means less to load, less to check, and fewer places for problems to hide.

### What changed

- **Unused code removed** from the console, the shop server and the repair engine. This includes the leftovers of an older backup storage design, an unused router port-mapping feature, old runtime-install helpers that the required prerequisites step replaced, the old local sign-in window, and four server commands no console ever sent.
- **The repair engine no longer updates itself from a shared folder.** This old opt-in feature copied files over the program with no integrity check. TronForged updates only through the shop server.
- **Image restore is stricter.** Leftover handling for the retired boot stick is gone, so a restore that cannot tell which disk holds the running Windows always refuses instead of warning.
- **Otherwise, nothing you see or use changes.** Every screen, report, repair, backup, remote session and update works exactly as in 0.449.15. The full test suite, the window checks and the update-swap test all passed before release.

### What to do

- Nothing. Your PCs update as usual. Update the shop server with `TronForged.Server-0.449.16.exe` when convenient.
