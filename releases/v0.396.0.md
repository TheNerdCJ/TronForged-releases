## v0.396.0 - PowerShell 7 can actually install now

**If the Prerequisites section has been telling you PowerShell 7 cannot be installed because a
file in the archive is not signed by Microsoft, that was our bug, not a problem with the
download.** It is fixed.

### What was wrong

Before installing PowerShell 7, TronForged checks every program file inside Microsoft's
archive and refuses anything that is not properly signed. That check required every single
file to be signed by Microsoft themselves.

Microsoft's own PowerShell package does not meet that bar - and it should not have to. Of the
350 program files in the official archive, 349 are signed by Microsoft and one is signed by
the .NET Foundation, who wrote it. Microsoft ship it that way deliberately. So the check
refused the genuine article, every time, on every machine.

### What changed

The check still looks at every file, and it still refuses anything whose signature is missing
or broken - that is the part that would catch a tampered download, and it is untouched.

What changed is which files must be Microsoft's specifically. PowerShell's own engine files
must be signed by Microsoft, as before. A supporting library that Microsoft chose to bundle
may be signed by whoever wrote it, provided its signature is valid. Any such file is now
recorded, so if a future PowerShell release brings a new one, it shows up rather than passing
unnoticed.

The archive as a whole is still checked against the exact SHA-256 that Microsoft publish for
that release before any of this happens, so the set of files is Microsoft's own to begin with.

### Worth knowing

PowerShell 7 is not required. Without it, repairs run on the Windows PowerShell 5.1 that every
Windows PC already has - that has always been true and has not changed. This release means the
automatic install can now succeed instead of retrying and failing once a day.

Assets: `TronForged-0.396.0.exe` + `.sha256`, `TronForged.Server-0.396.0.exe` + `.sha256`.
