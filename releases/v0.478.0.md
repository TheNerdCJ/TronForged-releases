# v0.478.0 - TronForged 0.478.0 - Big-screen text, portal invoices, stronger connection keys and safer imaging

## TronForged 0.478.0 - Big-screen text, portal invoices, stronger connection keys and safer imaging

This release also carries everything planned for 0.476.0 and 0.477.0, which were not published on their own.

### Easier to read
- Two new console text sizes, Extra large and Huge, for a console shown on a 4K TV. The Inventory tab follows the chosen size, and the console is sharp on high-DPI screens.

### Customer portal
- Customers can see their invoices under My shop account > My invoices, download each one as a PDF, and pay online through Square's own page when the shop has sent a payment link.
- A customer can no longer add, remove or share files on a ticket that has been closed. Staff still can.

### Privacy and security
- Customer sign-ins are recorded by account number and a one-way keyed hash of the email address, not the address itself. The privacy notice says so.
- Consoles and the shop server now agree their connection keys with a standard method (HKDF-SHA256). Both ends check that they agreed on it, so a connection cannot be quietly pushed back to the older method. Older consoles still connect, using the older method.
- The old relay program, replaced long ago by the shop server's own rendezvous, has been removed.

### Fleet, scheduling and remote access
- A RepairShopr re-import only adds customers the server does not already have. It never overwrites an existing record, and the summary counts the ones it skipped.
- Update now can be run for one whole customer at a time, and the shop server refuses any PC its rollout ring has not reached yet.
- The organizer tree can show Businesses or Households.
- A calendar visit shows every technician booked on it, not just the first.
- Before anyone signs in on a PC, the Tech, Ticket and Customer boxes a technician fills in are shown only to that technician's viewer.
- Secure connections are closed properly when a viewer disconnects or reconnects, and Reconnect and Connect start a viewer the same way.
- If a Defender exception was added for a PC, the Fleet PC details show it.
- If a fleet repair restart never started, the tile says "not started". On a PC already on the newest release, the helper line points to Install helper.

### Imaging, repairs and backups
- Boot in VM, Encrypt, sealing a kept image and sending an image to its destinations check the image and use it while it is held, so it cannot change between the check and its use.
- A system image sent to a network share no longer puts the share's password on the backup command line. If the PC cannot sign in to the share, the image is skipped and the run says why.
- The KMS activator cleanup, the USB selective suspend fix and both print spooler purges save what they change before changing it, so Revert can bring it back.
- Long hidden jobs keep the PC awake until they finish. Old copies of opened PDFs are cleaned up after a day.
- A recovery step started before a ticket was chosen is saved to the ticket you choose later.
- Labels sent to a printer chosen in Settings no longer freeze the window while printing.
- A part of a run that is already running again after a restart keeps its saved progress and is not started twice. A run reads its tools' output in the PC's own console code page.

### Server and invoices
- Tax certificate files are copied and checked when you move the backup location, and an upload is refused with a clear message when the disk is full.
- Ready to pick up and ticket search find tickets older than the newest 200.
- The server keeps who created each pairing code, which pairing code each console joined with, and the text of queued run emails, so these survive a restart.
- Invoice emails and printed invoices hide any card number found in the shop's own settings. When the card number scan finds a number but could not check some values, the Status page shows a red line with the count.
- Every setting the console saves goes through one locked writer, so two saves at the same moment can no longer lose one of them.

### What to do
- Update the shop server and the consoles as usual. The server upgrades its database once on first start; check that its disk has room for one extra copy of the database first.
- If a system image goes to a network share, check that the share's user can sign in from the PC with the saved details.
