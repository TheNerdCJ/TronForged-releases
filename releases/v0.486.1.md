# v0.486.1 - TronForged 0.486.1 - Larger fleets and faster backups

## TronForged 0.486.1 - Larger fleets and faster backups

This release is about the shop server. It lets one server look after a much larger number of PCs, and it moves backups and updates with far less work.

### Server

- **More PCs at once.** The server now keeps track of every connected PC, however many there are. Before, it stopped counting after about 500, so on a large fleet some PCs looked offline when they were not, chat messages could miss them, and revoking a lost PC did not always cut it off straight away. Revoking a PC now closes every connection it has open.
- **Remote control for the whole fleet.** The server can now hold a waiting connection for every PC in a fleet of thousands. Before, it turned PCs away after about 250 with "Too many machines are waiting", and Connect failed for the rest.
- **Lighter on the server.** A PC that is connected but quiet no longer ties up a thread on the server, so thousands of PCs can stay connected at once. This also helps a shop whose internet traffic reaches the server through another computer on its own network.
- **Faster backups and restores.** Backup pieces now travel as plain bytes instead of being converted to text and back. Large backups and disk images use much less memory and processor time on both ends.
- **Faster updates for many PCs.** When many PCs download the same update, the server prepares each piece once and sends it to all of them, instead of preparing it again for every PC.
- **Safer backups after a power cut.** Each backup piece is now written all the way to the disk before the server records it as saved.

Older consoles keep working with this server, and consoles from this release keep working with older servers: the faster backup and update transfers are used only where both ends support them.
