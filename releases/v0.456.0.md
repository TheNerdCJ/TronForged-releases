# v0.456.0 - TronForged 0.456.0 - TronForged runs only what it has checked; privacy policy; PC Transfer moves the screen saver

## TronForged 0.456.0 - TronForged runs only what it has checked

This release is about trust: the repair engine, the ISO tab and the winget repair now check what they are about to run, and refuse what they cannot vouch for.

### The repair engine is checked before every run
- Before a run starts - from the console, from the before-login agent, or a scheduled maintenance run - TronForged compares every engine file in `TronForged.data\src` with the copy carried inside the installed program. A missing or changed file, or an extra script in that folder, stops the run with a message naming the file.
- To fix it, start the TronForged console again (it restores the files; delete an extra script yourself) or reinstall.
- Right after an update, the before-login agent refuses runs until its service has restarted onto the new version.

### The ISO Files tab
- **Fido** (the script that asks Microsoft for the current Windows link) is now one reviewed version, checked every time it runs. Only a download link on Microsoft's own download server is taken; anything else opens Microsoft's download page instead.
- **The Windows 10 row now downloads Windows 10.** Before this release it downloaded Windows 11.
- **Rufus** starts only when it is signed by its publisher, Akeo Consulting, checked again before every start. A copy that fails is deleted and rufus.ie opens instead.
- **In-place Upgrade** starts the mounted image's `setup.exe` only when Microsoft signed it.
- Ubuntu's link is updated to 24.04.5.1. Kali's row now downloads the installer image (Kali publishes its Live image only by torrent now; **Page** opens kali.org for it).

### Repair winget
- **Windows fixes > App Updates (winget) > Repair winget** first re-registers App Installer, and downloads it from Microsoft only if winget is still missing. The download is checked before it is installed, and is kept in a locked folder that is removed afterwards. The Patch stage installs App Installer the same way.

### PC Transfer moves the screen saver
- A screen saver that comes with Windows moves with its wait time and whether it asks for the password. One that is not part of Windows is named in the summary so you can install it - it is never copied.

### Privacy policy
- TronForged now ships with a **Privacy Policy** (PRIVACY.md, beside the licence in every install and on the releases page). In short: the software sends nothing about you or your customers to its publisher - everything stays on your shop's own server.
- A **privacy notice template** for your customers is installed beside it: fill in your shop's details, delete the lines for services you do not use, and have it reviewed for your area.
- The licence now names its publisher (Nycz Software Solutions, Hermiston, Oregon) and Oregon law, points to the privacy policy, and is corrected where the product had moved on: your server's database is encrypted (since 0.453.0) and staff sign in with an authenticator code (since 0.451.0).

### Other fixes
- A Defender scan type in a profile other than Quick or Full is now refused and reported, instead of being passed on.
- The remote catalogue of repair stages is now read from the engine itself, so it always matches what the engine can run.
- Several internal command lines (folder permissions, the server installer's firewall and service steps, moving the server's data) now quote paths correctly, including a drive root such as `D:\`.

### What to do
- Update the shop server, then the PCs.
- If a run says an engine file was changed, start the TronForged console again; if it still refuses, reinstall.
- After updating a PC, give the before-login agent a minute to restart before starting a remote run.
