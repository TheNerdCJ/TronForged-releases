## v0.384.0 - the restore point tells you the truth

Before this release, TronForged made a restore point before running Windows Fixes and then
said nothing about whether it worked. On a PC where System Restore is turned off by policy -
which is common, and common after malware - no restore point was created and the technician
was told the safety net was in place.

- **A restore point that could not be made now says so**, in front of the fix result, and the
  fix still runs. You decide whether to continue knowing there is no rollback.
- **There is now one restore point, not four.** The repair engine, the Windows Fixes hub, the
  manual "Create restore point" button and one of the fixes each had their own copy, and
  three of them used commands that are being retired by Microsoft.

Also fixed: three printer and USB fixes have been rewritten so their changes will still be
applied on newer versions of Windows PowerShell. On the current engine they worked; on the
next one, the read would have succeeded and the write would have quietly done nothing.

Assets: `TronForged-0.384.0.exe` + `.sha256`, `TronForged.Server-0.384.0.exe` + `.sha256`.
