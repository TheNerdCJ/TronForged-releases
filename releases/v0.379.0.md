## v0.379.0 - the licence

TronForged now ships with an **End User License Agreement**: `EULA.md`, installed beside every console and published in this repository. Installing or using TronForged accepts it, and the install screen says so.

- It describes the software **as built**: there is no vendor cloud (your shop's server is the only place your data lives, and the author receives nothing); what a connected Customer console lets the shop do - including remote access while you are away and before you sign in - and how to stop it; what the console reports to the shop; the third-party tools the repair engine downloads under their own terms; backups in the shop's custody; and the unsigned, pre-release status.
- **Shops:** on a customer's PC, the acceptance on the install screen is the customer's - show it to them before you install.
- The Customer console's Remote tab now says where the disconnect actually is: the tray icon's *Connect to my repair shop* item, which disconnects while connected.
- Every release from now on ends with the acceptance line and links the licence; the copy in this repository always matches the one inside the release.

Assets: `TronForged-0.379.0.exe` + `.sha256`, `TronForged.Server-0.379.0.exe` + `.sha256`.
