# v0.387.0 - The Windows.old warning reaches the report

## v0.387.0 - the Windows.old warning now reaches the report

When TronForged removed a previous Windows installation (Windows.old) and some protected
files could not be removed, that line never appeared on the customer's report. The successful
case always appeared, so the report looked complete.

- **A partial removal is now reported**, and it says what it means: a rollback to the old
  Windows may still be possible, and not all the space was reclaimed.

Nothing else changes. The removal itself behaved correctly throughout; only the report was
missing the line.

Assets: `TronForged-0.387.0.exe` + `.sha256`, `TronForged.Server-0.387.0.exe` + `.sha256`.
