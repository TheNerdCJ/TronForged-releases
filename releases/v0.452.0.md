# v0.452.0 - TronForged 0.452.0 - every remote session is approved by the shop server

## TronForged 0.452.0 - every remote session is approved by the shop server

### Remote control, one session at a time

- **Technicians no longer hold a permanent key to each customer PC.** Until now, every technician with remote access received each PC's standing access token, and a copy kept working after the technician left, had their password reset or lost remote access. Now the token never leaves the shop server.
- **The shop server approves each session.** When a technician connects, the server checks they still have remote access, are not a customer account, and that the PC is still enrolled. It then issues a pass for that one session, naming the PC and the technician and expiring in five minutes. The PC accepts each pass once. Removing a technician's access stops their next session immediately.
- **The PC records the technician the server named**, not whatever name the technician's console claimed.
- **Two-factor before remote control.** An account that has set up its authenticator app enters a fresh code before each remote session. Five wrong codes pause remote control for ten minutes.
- **The direct connection over the shop's network is retired.** Customer PCs no longer accept remote sessions from the local network; every session goes through the shop server, where it is recorded.

### What to do

- **Update the shop server first, then the PCs.** A PC still on 0.451.0 or older cannot be reached for remote control until it updates; the console says so when you try.
- Nothing else changes for technicians: connect from the fleet list as before.
