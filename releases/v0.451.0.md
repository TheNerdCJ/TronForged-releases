# v0.451.0 - TronForged 0.451.0 - two-factor sign-in

## TronForged 0.451.0 - two-factor sign-in

### Sign-in now asks for a code from your phone

- **Every shop account - administrators and staff - can now sign in with a code from an authenticator app** (Microsoft Authenticator, Google Authenticator, Authy, 1Password...) as well as its password. The shop server enforces it, so it applies on every console.
- **You have two weeks to set it up.** The first time each account signs in on 0.451.0, it is offered **Set up now** or **Later**, and told how many days are left. Nothing changes for anyone until they set it up or the two weeks run out.
- **After two weeks the password still signs in** - nobody is locked out - but the console asks for the setup straight away, and the account can do nothing else until it is done.
- **Setting it up takes a minute:** add an account in the app, type the key the console shows, and enter the 6-digit code the app gives back. From then on, signing in asks for the current code.
- **Customer-portal accounts are not affected.** They keep signing in with their password.

### Lost or new phone

- An administrator opens **Server Console > Users** and presses **Reset 2FA** on the account. It signs in with its password again and gets a fresh two weeks to set up the new phone; it is signed out everywhere at once.
- If the shop owner's own account loses its phone, **Create/reset administrator on the server PC** clears it.

### What to do

- Update the shop server and the consoles as usual, then have everyone set up their authenticator in the next two weeks.
