# v0.445.0 - For the record only - restart, report and remote-support fixes (install v0.446.0)

Published for the record after v0.446.0. Install the latest release instead: it includes everything here and later fixes.

**This release is published for the record only.** It is not offered as an update: shop servers, consoles and new installs never receive it. Install v0.446.0 or later instead - it carries everything below plus fixes to it, and its release notes cover v0.443.0 through v0.446.0.

What v0.445.0 added, on top of v0.443.0 and v0.444.0:

- **Restarts wait for long jobs.** A console's idle self-update, and **Restart when the PC is next idle** after Windows updates the shop sent, wait for a Data Recovery job, a forensic collection, a Windows ISO or tool download, the PowerShell 7 install, a network settings change and Windows updates in progress, as well as a service run, disk imaging and remote sessions. **Install and restart** names the job it would stop and defaults to No.
- **Service Desk and reports.** **Stop Safely** stays on screen at the console window's narrowest width; **Choose machine...** on a ticket links the machine instead of answering *No such machine.*; the final report of a Safe Mode scan or Windows-updates run that restarts the PC is recorded and attached to its ticket; **Files > On this PC** lists more of a ticket's reports; a customer console's Reports tab says where its reports are kept.
- **Remote support.** **Install helper** and **Enable UAC / lock-screen control** replace an out-of-date full-control helper with the PC's own copy; Ctrl+Alt+Delete reaches a replaced helper without reconnecting; a remote session that reconnects by itself keeps the Ticket box you applied.
- **Customers.** A save from a copy opened before someone else renamed the customer keeps the new name; customers imported from RepairShopr are protected from consoles older than v0.438.0; **Import customers (CSV)...** says to update an older shop server instead of failing row by row.
- **Access and privacy.** A login linked to a customer is refused the shop's billing actions - creating, sending, voiding and emailing invoices, recording payments, billing time, Square payments and the accounting reports and exports; technician tray alerts never appear on a customer's PC, even with a technician signed in there; and the shop server removes the customer's name, the ticket number and the report's location from a **Draft customer summary** request before it reaches the AI service.

Problems found in this version are fixed in v0.446.0. Among them: a login linked to a customer but left in a staff group could still see every customer's invoices; a technician console that had started a remote-control session stopped installing its own updates when idle, and held back the restart that finishes Windows updates; **Choose machine...** told a reception login that the customer had no machines; **Install helper** and **Enable UAC / lock-screen control** could put an older helper over a newer one; and the AI settings page could show a change as failed when it had been made. If you installed v0.445.0 by hand, update that PC to v0.446.0 and then restart it: until it restarts, an **Enable UAC / lock-screen control** answered at the Windows sign-in screen can put the older helper back once.
