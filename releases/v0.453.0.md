# v0.453.0 - TronForged 0.453.0 - faster, sturdier PC transfers, an encrypted shop database, safer updates

## TronForged 0.453.0 - faster, sturdier PC transfers, an encrypted shop database, and safer updates

### PC transfer
- **Transfers survive Wi-Fi drops.** A connection that dies without warning is noticed in under a minute and the transfer resumes. Both PCs stay awake while it runs, and the new PC keeps its door open until the pairing ends - choosing what to move no longer has a 10-minute limit.
- **Clear answers when it cannot connect.** The old PC says when the new PC stopped waiting, or whether the new PC answered but was not waiting versus nothing answering at all (a firewall or the Wi-Fi blocking it).
- **A check code on both PCs.** After pairing, both screens show the same six digits - a different number means the wrong PC.
- **A summary before it starts**: what will move, how many programs reinstall, copy or need you, and which licences to free on the old PC first.
- **Faster.** Each file is written to disk once, not after every megabyte; a cable is used before Wi-Fi; on Wi-Fi, pieces that shrink are compressed; each piece is checked once, not twice; build and cache folders (node_modules and the like) are left behind; program reinstalls start while the files are still arriving.
- **More programs move on their own.** Programs winget lists under a shortened name are still found, Microsoft Store apps reinstall, per-user apps that never recorded their folder can be copied, and program look-ups run four at a time and are remembered.
- **Programs winget cannot reinstall** get advice: a licence to free first (Adobe, Office, Autodesk, QuickBooks, antivirus), a matching signed installer found on the old PC, and the vendor's download link.
- **Files the new PC already has are not sent again**, even on the first transfer (a re-run, or files OneDrive already brought down).
- **A restart does not end it.** If either PC restarts, opening Data Migration again picks the pairing back up; what was already sent is not sent again.

### Shop server
- **The shop database is encrypted** (SQLCipher, AES-256), under a key derived from the server's own sealed secret. An existing database is converted once, the first time the server starts on 0.453.0; a copy of the unencrypted database is kept beside it for 7 days, then removed. Backups taken from it are encrypted too.
- **The Status page says whether the database is encrypted, and warns when its drive is not BitLocker-encrypted.**
- **A recovery copy of the database**: `TronForged.Server.exe --db-backup --file <path> --recovery-key` writes a copy locked with a new key it shows once - keep that key apart from the file; `--db-restore --file <path> --recovery-key <key>` restores it on any server.

### Updates
- **A PC never installs an older version** than the one it runs.
- **Checks before an update starts** (enough free disk space), so an update that cannot finish never begins.
- **Updates download only what changed** - most of a new version is already on the PC, so a typical update fetches about a tenth of the program.
- **Update from a USB drive** (tray menu) for a PC that cannot reach the shop server, with the same signature checks as a download.

### Two-factor sign-in
- **The setup screen shows a QR code** to scan; the key is still shown for typing.

### Fleet readiness
- **Reconnects by itself** when the link to the shop server dropped, and has a **Refresh** button.

### What to do
- Update the shop server first (its database is encrypted on that start - keep the server running until it says it is back), then the PCs.
