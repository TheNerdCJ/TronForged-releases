# v0.463.0 - TronForged 0.463.0 - Smoother remote desktop

## TronForged 0.463.0 - Smoother remote desktop

### Remote desktop keeps up with slow lines
When the customer's internet upload is slow, the picture now switches to a lighter, smaller version
so the session stays responsive, and goes back to the normal picture once the line improves.
If part of the picture is ever missed, the viewer asks for a fresh one straight away instead of
waiting.

### See the customer's mouse pointer
The customer's pointer is now drawn over the picture, so you can see where they are pointing.
(Not yet on the sign-in screen before anyone has logged in.)

### The customer's console no longer freezes
Messages, Ctrl+Alt+Delete and switching screens no longer freeze the customer's console while a
large picture is being sent.

### Several monitors and very large screens
Remote desktop on a PC with several monitors now uses the faster Windows capture method when it
can, and large screens are scaled down for the picture in less time. A very tall desktop (screens
stacked on top of each other) is shown scaled down instead of not at all.

### Safer
The viewer checks the size of every picture before opening it, so a damaged or hostile picture
cannot exhaust the technician's PC.

### What to do
Nothing. Consoles and the shop server update as usual. If you use PCs with several monitors, tell
us how remote desktop behaves on them.
