# v0.378.0 - The release feed is public

## v0.378.0 - the release feed is public

TronForged releases are now published to this public, releases-only repository (`TheNerdCJ/TronForged-releases`): four files per release and nothing else. The product source stays private.

- **Installers read this feed without a token.** The check for a newer release that `TronForged.exe` makes before installing (v0.377.0) now works on every PC, not only on the server box.
- **Shop servers read this feed without a token.** A fresh server needs no GitHub token at all.
- **Servers set up before v0.378.0:** in *Server Console -> Settings -> Console updates*, set *Release feed* to `TheNerdCJ/TronForged-releases` and click **Remove token**. An empty field on an older server still means the old private repository, and a leftover token that later expires would make even a public feed answer 401.
- **When the feed cannot be read, the reason is named** - a rate limit on a shared address, an expired token, a private or empty feed - instead of "could not reach". The server writes one audit row per change in that reason, rather than nothing.
- The *Console updates* page no longer calls the token required.

Assets: `TronForged-0.378.0.exe` + `.sha256`, `TronForged.Server-0.378.0.exe` + `.sha256`.
