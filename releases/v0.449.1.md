# v0.449.1 - v0.449.1: PowerShell 7 installs with Microsoft's MSI first, the signed ZIP as the fallback

## TronForged v0.449.1

### PowerShell 7 now installs with Microsoft's installer

When TronForged installs PowerShell 7 on a PC (automatically in the background, or from the
"Install PowerShell 7 now" button in Settings), it now uses Microsoft's own MSI installer first.
Every optional extra is switched off: no PATH change, no remoting, no Microsoft Update, no Explorer
menus, no telemetry. The installer must match the checksum Microsoft publishes and carry Microsoft's
signature before it runs, and every program file it installs is checked the same way the ZIP package
always has been.

Microsoft's signed ZIP package is still used when the MSI cannot be:

- PowerShell 7.7.0 and later: Microsoft no longer publishes an MSI.
- Safe Mode: Windows' installer does not run there, so a repair that resumes in Safe Mode uses the ZIP.
- Any MSI step that fails (download, checksum, signature, the install itself, or the check afterwards).

The status line in Settings says which one was used, and why the MSI was skipped when it was. A
PowerShell 7 that TronForged installed with the MSI is removed through Windows' installer when you
press Remove; one installed by anyone else is still left alone.

### What you need to do

Nothing. Existing installs keep working and are updated the next time PowerShell 7 is updated.
