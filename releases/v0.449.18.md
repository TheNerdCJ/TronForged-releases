# v0.449.18 - TronForged 0.449.18 - Advanced Tune-Up and Data Migration from a dead PC's drive

## TronForged 0.449.18 - Advanced Tune-Up, and Data Migration from a dead PC's drive

A new service for PCs that need more than a tune-up: the useful parts of the popular Windows "debloat" builds, without the parts that make a PC less safe. And a customer whose old PC will not start can still have their files moved to the new one.

### Data Migration: the old PC will not start

- **Move a customer's files straight from the old PC's drive.** Connect the old drive to the new PC (a USB dock or adapter), open Data > Data Migration, choose who receives the data, and press **Scan for the old PC's drive**. TronForged finds the old Windows and lists its users; choose one, **Move from this drive**, tick what to move and **Start transfer**.
- **The old drive is only read.** Nothing is ever written to it. Every file is checked as it is copied, a restore point is made on the new PC first, and a file already on the new PC is kept beside the new copy.
- **What comes across:** the user's folders (Desktop, Documents, Pictures and the rest), their app data, browser bookmarks and wallpaper. **What does not:** Wi-Fi passwords, network printers, mapped drives and programs - the summary lists them so you can set them up again.
- **A BitLocker-encrypted drive** is shown as locked: unlock it in File Explorer with the old PC's recovery key, then scan again.

### New

- **Advanced Tune-Up service.** Pick it on the Automated service page, after Tune-Up. It does everything Tune-Up does, and also:
  - switches off Windows' feedback prompts, advertising ID, tips and suggestions, lock-screen tips, Start recommendations and the "finish setting up your device" reminders, for every user of the PC and for new users;
  - keeps typing and handwriting data on the PC, and shows Start menu search results from the PC only (no Bing results);
  - disables the scheduled tasks that only collect and send usage data;
  - sets diagnostic data to the minimum Windows allows, and lets the PC share update downloads only with PCs on the same network;
  - switches off background game recording, the delay before startup apps open, and Fast Startup (so a shutdown is a full shutdown and updates finish properly);
  - sets two rarely used services (Downloaded Maps Manager and Distributed Link Tracking) to start only when something needs them.
- **Windows Fixes > Advanced Tuneup.** Each of these settings on its own, plus some that change what the customer sees and so are never automatic: Windows' telemetry services, error reporting, location services, lean visual effects, Edge running in the background, Widgets, background apps, and OneDrive sync. Each of those shows a warning and asks first. OneDrive is never uninstalled, and its sync is not switched off while a user's Desktop, Documents or Pictures are kept in OneDrive.
- **Windows Fixes > Advanced Tuneup (Put Back)** puts back Windows' own setting for each one.
- **The tune-up removes a few more retired Windows apps:** Cortana, Bing Search, Dev Home, Paint 3D and Maps. They can be reinstalled from the Microsoft Store.

### Safety

- **Your PC's protection is never changed.** Advanced Tune-Up will not touch Microsoft Defender, SmartScreen, User Account Control, Windows Update, Memory Integrity and other virtualization-based security, the processor security fixes, the firewall, BitLocker, driver signing or the files Windows needs to repair and update itself. TronForged refuses such a change even if it is asked for.
- **Everything can be undone.** A restore point is made first, every change is saved to the service's undo record before it is made, and "Revert this run's tweaks" puts a whole service back.
- None of these settings are offered on the customer's own console.

### What to do

- Nothing. Tune-Up and the other services work as before, apart from the five retired apps above. Moving from an old drive needs no shop server update.
